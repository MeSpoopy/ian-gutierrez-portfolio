Sunrise clock widget

A location-aware Zoho Creator widget brings sunrise time, the current date and time, coordinates, and timezone together in one display.

The problem

Sunrise changes with location and date. Users needed a prominent display that brought location-specific sunrise information and current time together, with minimal navigation or manual calculation.

The approach

I built the widget with HTML, CSS, and JavaScript inside a Zoho Creator page. It reads the browser location, converts time data for display, and updates the clock and location information.

Implementation highlights

  • HTML structures the interface, while CSS provides a large, readable clock display.
  • JavaScript manages coordinates, dynamic display updates, and time conversion.
  • Zoho Creator hosts the page and widget.
  • If location access is denied, the widget uses default or limited data, with guidance in the user manual.

The outcome

Users can view their current time, location, timezone, and sunrise time on one screen, with a fallback when location access is unavailable.
