AI résumé analyzer

The problem

The workflow needs to connect résumé submission, job-specific analysis, applicant storage, and HR notification across several Zoho services. The applicant’s chosen role must remain associated with the correct résumé and score throughout the process.

The proposed solution

Applicants would select a job and submit a résumé. The planned analysis uses the OpenAI API to compare the résumé with that job description and return a match score. Creator would store the applicant details and score, with Flow connecting the record to Mail and Recruit.

Planned implementation

  • Associate each submission with the applicant’s selected job and its description.
  • Store applicant details and the generated match score in Zoho Creator.
  • Use Zoho Flow to send the applicant’s name and score to HR through Zoho Mail.
  • Transfer applicant data to Zoho Recruit as part of the connected workflow.

Expected value

The proposed workflow is intended to give HR a consistent place to review applicant information and scores while reducing repeated data entry across Creator, Mail, and Recruit.

Proposed application flow

A summary of the supplied solution design.

From submission to HR review

  1. Select job & submit résumé
  2. Compare with the job description via OpenAI API
  3. Store applicant details & score in Creator
  4. Connect records through Flow
  5. Notify HR in Mail & share data with Recruit

Proposed workflow only. The supplied document describes planned implementation; it does not present a completed application or a live product screenshot.
