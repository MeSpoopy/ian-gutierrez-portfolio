# Design — Connection studio

## Direction
User-pinned: cinematic dark mode, nearblack surfaces, warmwhite type, disciplined acid-lime. The hero is an unboxed editorial composition around three interlocking machined channels. Applications, automation and intelligence controls connect the object to relevant actual case studies. Native scrolling joins the structure slightly; pointer movement adjusts its view. This metaphor is clearly decorative, never represented as a live system or measured result.

## Surfaces and typography
Canvas #0b100f; surfaces #141d19 and #121d16; text #eef2e8; muted #abb8ad; action #d5f26d with #11190c text. Manrope display <=96px, DM Sans body, tracking no tighter than -.04em. Responsive asymmetric work grid; real screenshot evidence remains unaltered. White is reserved for the original images and logos, never full reading panels. Component corners 12px, action pills, scene unboxed.

## First viewport and path
Name/role, two-line value proposition, clear work/contact links and direct application/automation/intelligence case links. The interactive object owns the open right half on desktop; compact artwork follows readable content on mobile. Selected work > additional projects > method > about and experience > education > recognition > contact. Zoho work remains first.

## Motion and access
650–850ms authored entrances; 180–280ms feedback. No scroll interception. Active object scales subtly; native group buttons expose selected state. Pause motion stops decorative movement globally. Still artwork is an explicit alternate to WebGL and the automatic failure state. Demand rendering for pause/offscreen/hidden tabs, DPR<=1.5. Hover transformations only on fine pointers; focus states immediate. All copy visible by default.

## Reference interpretation
Oryzo demonstrates a persistent product object, scene transitions and clear typographic hierarchy. This implementation translates continuity into original connected forms and real portfolio evidence, without copying its assets or fictional claims.

## Direction exploration
Grounded families considered: product studio, architecture monograph, transit interchange, technical publishing, sculpture gallery, assembly drawing, connection studio. The final connection-studio composition follows the user's pinned dark/material direction and the assigned seventh candidate. Alternative motifs were not adopted: scientific instruments suggest diagnostics, travel ephemera suggests destinations, folk ornament suggests craft unrelated to this product. Their useful disciplines—consistent states, clear routes, deliberate color hierarchy—inform implementation without copying their visual motifs. User explicitly requested independent implementation rather than another approval round.
